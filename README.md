# booldata conference materials

This repository is where booldata shares the materials, demos, and resources presented in conferences, events, webinars, and technical sessions.

Our goal is to make valuable content easy to access, reuse, and explore by the wider community. Here you will find examples of work presented by booldata, including reports, sample models, technical demos, code, notes, and supporting assets.

For more information about booldata, visit [booldata.com](https://www.booldata.com).

## What is included

This repository brings together conference-related content such as:

- presentation materials
- demo files and sample data
- Power BI and analytics assets
- scripts and supporting code
- session notes and references
- workshop and event resources

## Repository structure

The content is organized by event, session, or topic so it remains easy to navigate and discover.

## How to use this repository

- browse the folders to find materials for a specific conference or topic
- open the related project files in the relevant tools, such as Power BI Desktop
- reuse demos and examples as inspiration for your own learning, testing, or internal work
- share the materials with colleagues, partners, or event participants when useful

## Contribution guidelines

This repository is intended as a shared knowledge base for booldata content. When adding new materials:

- keep filenames and folder names clear and descriptive
- include a brief explanation or context for each asset
- avoid sharing sensitive or confidential information unless explicitly approved
- maintain a consistent structure so materials are easy to find by event or topic

## Notes

This repository reflects booldata's commitment to knowledge sharing, technical visibility, and community engagement through practical, real-world examples from conferences and events.
